# Перенос проекта в Claude Code

Подготовлено 14.10.2026. Время: ~20 минут.

## Что в архиве
| Файл | Назначение |
|---|---|
| `CLAUDE.md` | Инструкции проекта (бывшие «инструкции проекта» claude.ai) — Claude Code читает их сам в начале каждой сессии |
| `docs/00…05` | Все документы проекта дословно; `02` — в `docs/archive/` (устарел) |
| `.claude/settings.json` | Права: Битрикс только чтение (86 запретов на запись), Drive без удаления, `.env` не читается |
| `.claude/commands/` | Команды `/start` (сводка по паспорту) и `/passport` (обновить паспорт) |
| `.gitignore`, `.env.example` | Секреты и выгрузки не попадут в git |

## Шаги
1. **Установить Claude Code** на ноутбук (если ещё нет): инструкция — https://docs.claude.com/en/docs/claude-code/setup. Войти тем же аккаунтом claude.ai (`claude` → вход через браузер).
2. **Распаковать архив**, например в `~/Projects/90gradusov`, и запустить там: `cd ~/Projects/90gradusov && claude`.
3. **Проверить подключения**: команда `/mcp`.
   - Коннекторы claude.ai (Google Drive и, возможно, Битрикс «90») могут подтянуться сами — должны быть видны в списке. Если не видны — НЕ ИЗВЕСТНО, синхронизируются ли они на вашем тарифе; тогда шаг 4.
   - Если Битрикс не виден: добавить Evrika MCP вручную, адрес взять в кабинете Evrika (тот же, что в настройках коннектора claude.ai):
     `claude mcp add --transport http 90 "<адрес из Evrika>" -s local`
     Имя сервера — ровно `90`, иначе не сработают запреты на запись. Флаг `-s local` хранит адрес только у вас на компьютере, не в проекте. Адрес и токены в чат не присылать.
4. **Проверить запрет записи**: попросить «создай тестовую задачу в Битриксе» — Claude должен получить отказ по правам. Затем `/start` — должна прийти сводка по паспорту.
5. **Git (по желанию, рекомендую)**: приватный репозиторий в аккаунте компании на GitHub → `git remote add origin <адрес>` → `git push -u origin main`. Локальный репозиторий с первым коммитом уже создан.
6. **Проект claude.ai «90 Градусов»** не удалять минимум до конца этапа 2: там остаётся история чатов. Новые документы ведём только в `docs/` — иначе будет два расходящихся паспорта. В инструкции проекта claude.ai можно дописать: «Проект перенесён в Claude Code, документы здесь не обновляются».

## Что меняется в работе
- Документы — обычные файлы: Claude правит их сам, без ручной загрузки в проект.
- «Новый чат на каждый этап» → новая сессия `claude` в папке; контекст даёт `CLAUDE.md` + паспорт. Длинную сессию сжимать `/compact`.
- Расчёты — скрипты в `scripts/`, выгрузки — в `data/` (не в git).
- Голосовые по-прежнему присылать текстом.

## Не известно / проверить
- Транспорт Evrika MCP (http или sse) и сам адрес — посмотреть в кабинете Evrika. Пробный период до 27.10.2026.
- Точные имена инструментов в Claude Code (`mcp__90__…` или `mcp__claude_ai_90__…`): в `settings.json` запреты стоят на оба варианта; если в `/mcp` сервер называется иначе — сообщить Claude, он поправит правила.
- Google Sheets-коннектора по-прежнему нет: Таблицы читаются через Drive.
