# Отчёты по запросу (бот сводки)

Тот же Telegram-бот, что присылает ежедневную сводку. Отвечает только владельцу (`TG_CHAT_ID`).

| Команда | Что | Источник |
|---|---|---|
| `отчёт [период]` / `/report` | лиды по источникам и статусам, конверсия, причины отказа; первый ответ клиенту (медиана, доля ≤2 раб. ч); КП в переписке; оплаты, провалы, отгрузки; сравнение с прошлым периодом той же длины | Б24 + переписка Wazzup, считает код |
| `лиды [период]` / `/leads` | только лиды и статусы (быстро) | Б24 |
| `висят` / `/hanging` | ждут ответа > 2 раб. ч; после КП молчат → 1-е / 2-е касание / закрыть | хвосты переписки открытых лидов за 45 дней |
| `воронка` / `/funnel` | открытые лиды по статусам, сделки продаж и производства по стадиям с суммами, зависшие, без суммы, «Отгружено» не закрытые | Б24 |
| `план` / `/plan` | план дел менеджера прямо сейчас (как утренняя рассылка 10:00) | Б24, считает код |
| `клиент 1251` / `клиент сд761` / `клиент Имя` | саммари истории: заказ, договорённости, обещания, риски, открытые вопросы | Б24 + Claude API |

Периоды: сегодня, вчера, неделя, прошлая неделя, месяц, прошлый месяц, «сентябрь», «май 2026», «30 дней», квартал, прошлый квартал, год, `01.09-15.10`, `01.09.2026-30.09.2026`. Без периода — текущий месяц.

Ключи в `.env`: `TG_BOT_TOKEN`, `TG_CHAT_ID`, `B24_AGENT_WEBHOOK` (только чтение), `ANTHROPIC_API_KEY` (только «клиент»).

Ограничения (ДОПУЩЕНИЯ):
- Переписка до 26.09.2026 загружена в Б24 разом — время ответа по ней не считается, отчёт предупреждает.
- «КП в переписке» — поиск цены в тексте менеджера; КП, отправленное только файлом, не видно.
- «Зависла»: продажи > 7, производство > 14 календарных дней на стадии (`STUCK_DAYS`).
- Висят: короткие «спасибо / хорошо / ок» клиента ответа не требуют; ожидания > 3 раб. дн. — отдельной строкой (возможно, ответили не в Telegram).

Проверка из консоли: `cd app/reports && ../../.venv/bin/python reports.py period 2026-10-01 2026-10-20` (также `hanging`, `funnel`, `client 1251`).
Запуск: launchd `ru.90gradusov.reports-bot` (`scripts/launchd/`), лог `data/reports/bot.log`.

Доступ: владелец (`TG_CHAT_ID`) — все команды; менеджер (`data/reports/digest_config.json`) — только «план», «висят», «клиент», «помощь». Запросы выполняются параллельно.
