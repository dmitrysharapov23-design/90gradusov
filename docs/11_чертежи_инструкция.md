# Чертежи: как складывать на Google Drive

Для проектировщиков. На один заказ уходит около минуты: создать папку, положить файлы, вставить ссылку в сделку.

## Где
Google Drive → «Чертежи 90 градусов» → **«Заказы»**.
Старые папки («Проекты», «Проекты Сергей», «Серийка», «Яндекс умер») — архив, их не трогаем и не переименовываем.

## 1. Папка заказа — одна на заказ
Имя: **`<номер сделки производства>_<клиент>`**
Пример: `717_Силов`

- Номер — ID сделки в воронке «Производство» Битрикса: открыть сделку, число в адресной строке или в заголовке карточки.
- Клиента писать коротко, одним-двумя словами.

Внутри две папки:

| Папка | Что кладём | Правила имён |
|---|---|---|
| `работа` | Всё рабочее: SolidWorks, черновики, фото, файлы от клиента | Любые, как удобно |
| `согласовано` | Только то, что клиент утвердил и что идёт в цех | Строго по образцу ниже |

## 2. Имя согласованного файла
**`<позиция>_rev<N>.pdf`** и рядом такой же **`.dxf`**

Примеры: `717-01_rev1.pdf`, `717-01_rev1.dxf`

- Позиция — номер из КП и маршрутного листа (`717-01`, `717-02` …). Если позиция в заказе одна, пишем просто номер заказа: `717_rev1.pdf`.
- Дату в имя не пишем: Drive сам показывает, когда загружен файл.
- Если чертёж делал не ты (например, внештатный чертёжник), допиши его фамилию: `717-01_rev2_Андрей.pdf`.

## 3. Клиент утвердил → кладём в «согласовано»
1. Выгрузить из SolidWorks PDF (векторный, не скан) и DXF.
2. Назвать по образцу и положить в `согласовано`.
3. Если клиент утвердил изменения, сохранить новую версию: `rev2`, `rev3`… **Старые версии не удалять** — по ним видно, что резали раньше.

## 4. Ссылка в сделке
Один раз на заказ: правой кнопкой по папке заказа → «Копировать ссылку» → вставить в сделку производства (комментарий или поле со ссылкой).

## Коротко
```
Чертежи 90 градусов/Заказы/717_Силов/
  работа/          ← любые файлы
  согласовано/     ← 717-01_rev1.pdf, 717-01_rev1.dxf, 717-02_rev1.pdf …
```
Цех работает только по файлам из `согласовано`. Файлы туда кладут только проектировщики.
