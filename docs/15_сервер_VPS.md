# Сервер (VPS): Claude и боты без рабочего Mac

Подготовлено 17.10.2026. Статус: **скрипты готовы, сервер не арендован**, на сервере ничего не проверено.

## Зачем
Сейчас бот КП, агент клиентов и входящие заявки работают, только пока рабочий Mac включён и не спит. На сервере они работают круглосуточно, а с Claude можно работать из любого места.

## Что переезжает, что остаётся
| | Где | Чем запускается |
|---|---|---|
| Бот КП, агент клиентов, входящие заявки, их два сторожа | **сервер** | systemd (`deploy/systemd/`), вместо launchd |
| Сторож сводки по чатам (`check-summary`) и сама сводка (задача Claude) | Mac | как сейчас |
| Клиентские выгрузки `data/b24`, `data/chats`, `data/calc`, готовые КП `data/kp/out` | Mac | не переносятся |
| Код и документы | оба, через приватный GitHub | `git pull` / `git push` |

На сервер копируются только `.env`, ключи Google, шаблон КП, `ignore_tg.txt` и файлы состояния ботов: что уже обработано, чтобы не было дублей лидов.

## Требования к серверу
- Ubuntu 24.04, 2 vCPU, 2–4 ГБ памяти, от 20 ГБ диска. Боты лёгкие, памяти нужно по запасу на Claude Code.
- **Страна не Россия.** ДОПУЩЕНИЕ: Claude API из России не обслуживается (403). Проверяется скриптом `check_server.sh`.
- При создании сервера указать SSH-ключ (ниже). Пароль root не нужен.
- Провайдер, цена, способ оплаты — НЕ ИЗВЕСТНО, выбирает владелец.

## Шаги
**Владелец**
1. Создать приватный репозиторий на GitHub и прислать его адрес. Claude привяжет репозиторий и отправит туда код.
2. Арендовать сервер по требованиям выше, при создании вставить SSH-ключ. Прислать IP-адрес.

**Claude (по SSH с Mac, каждый шаг с подтверждением)**
3. `deploy/setup_server.sh` от root: часовой пояс МСК, обновления, файрвол (только SSH), вход только по ключу, пользователь `gradus`, Claude Code. В конце выводит deploy-ключ.
4. **Владелец:** вставить deploy-ключ в GitHub → репозиторий → Settings → Deploy keys (включить «Allow write access»).
5. `deploy/install_app.sh <адрес репозитория>` от `gradus`: код, `.venv`, зависимости.
6. `deploy/push_to_server.sh gradus@<IP>` на Mac: секреты и шаблоны. Mac пока продолжает работать.
7. `deploy/check_server.sh` на сервере: ключи, доступ к Claude API, Telegram, Wazzup, Битриксу, Google. Секреты не выводит.
8. **Переезд** (с согласия владельца, лучше в нерабочее время): `deploy/push_to_server.sh gradus@<IP> --switch` останавливает задачи на Mac и переносит состояние. Затем от root `deploy/install_services.sh --start`.
9. Проверить: КП-бот отвечает на тестовое задание, в `agent.log` и `inbound.log` идут проходы, сторожа молчат.

**Владелец: Claude на сервере**
10. `ssh gradus@<IP>`, затем `claude` → вход по ссылке тем же аккаунтом.
11. Битрикс: `claude mcp add --transport http 90 "<адрес из Evrika>" -s local`. Имя сервера ровно `90`. Запреты записи приходят из `.claude/settings.json` через git.
12. Работа с сервером: в приложении Claude новая сессия по SSH на этот сервер, или `ssh` + `claude` из терминала, или Remote Control с телефона. НЕ ПРОВЕРЕНО, как Remote Control включается для сессии на сервере.

## Откат
На сервере `install_services.sh --stop`, затем на Mac `deploy/push_to_server.sh --back`. Перед возвратом скопировать с сервера свежие файлы состояния (`data/leads/inbound_state.json`, `data/client_agent/state.json`, `data/client_agent/external_sent.json`, `data/kp/bot/state.json`), иначе Mac повторит уже сделанное.

## Как работать вдвоём (Mac + сервер)
- Код меняется в одном месте за раз: в начале `git pull`, в конце коммит и `git push`.
- Боты работают только в одном месте. Два бота на одном токене мешают друг другу, два скрипта заявок создают дубли лидов.
- Логи на сервере: те же файлы в `data/…/*.log`, плюс `systemctl status 90g-kp-bot`, `systemctl list-timers '90g-*'`.

## Открытые вопросы
- **Персональные данные на зарубежном сервере.** Боты в работе сохраняют на диск сервера персональные данные: файлы и имена клиентов в КП (`data/kp/bot`), черновики ответов агента с текстом переписки (`data/client_agent/shadow_*.md`), реестр отправленных сообщений. По 152-ФЗ первичная запись и хранение персональных данных граждан РФ должны быть в России. НЕ ИЗВЕСТНО, как это применимо, если основная база — Битрикс24, а сервер только обрабатывает. Нужен ответ юриста до переезда (см. `docs/09`). Варианты: срок хранения рабочих файлов на сервере (например, чистить через 7 дней) или боты остаются на Mac.
- Страна и провайдер сервера, способ оплаты.
- Python на сервере 3.12, на Mac 3.9: зависимости совместимы — ДОПУЩЕНИЕ, проверяет `check_server.sh`.
